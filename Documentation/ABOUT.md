# Documentation

Experiment design, method records, findings and documents exchanged with the team.

| File | Purpose |
|---|---|
| [Setup/](Setup/) | **What we computed and how.** Method records for the setup, valid in every study: definition, code reference, which decision made it so, and what it feeds |
| [GAP/](GAP/) | Active study: design, recording requests, modelling plan |
| [Pilot_Noise/](Pilot_Noise/) | Closed study: both pilot summaries, decision statistics, recording requests of that period |
| [Analysis_Log.md](Analysis_Log.md) | Dated analysis log: what was done when, what was decided |

The old Office documents (the 26.08.2026 presentation and data summaries) are
kept as a historical record under `Pilot_Noise/archive/`; their numbers are out
of date. Current numbers are in the relevant study's folder and in `../CLAUDE.md`.

## Rule

If a metric feeds a decision, it gets a record under `Setup/`: definition,
code reference, options and why this one was chosen, evidence, what it feeds.
Anything not taken as-is from the literature is also marked: why it could not
be taken as-is, and what replaced it.
