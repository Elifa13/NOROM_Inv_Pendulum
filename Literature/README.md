# Literature

The project's source list. In Obsidian this file is the index; each basis
paper has its own note.

**Two statuses:**

- `basis`: a paper the study rests on. PDF in this folder, full note.
- `to-read`: to be read. Only a row in this index. Once read, it gets a note
  and its status becomes `read`.

The "Why it's listed" column is a reminder for unread papers, not a summary
of a reading. Its source is marked: *KK* = the old `Kaynak_Kaydi.docx`
(2026-09-01), *search* = the result title from the 2026-09-21 literature search.

To check whether a paper is in the repo, search by DOI. To start a new note,
copy `_template.md`.

`Kaynak_Kaydi.docx` stays as a historical record. This file is the current list.
